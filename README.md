================================================Method=========================================================================================
This is a project that analyzes structural variants among 4 patients. It uses 4 patient's BAM files generated from alligning the fastq files for each patient on the T2T CHM13 reference genome. From there a total of 16 variantions of vcf files were generated. 4 callers: SAVANNA, SNIFFLES, cuteSV, and nanomonsv were all used on each of the 4 patients. Nanomonsv does not require any germline data to filter out any noisy data because it is built to call somantic variants. However SAVANNA, SNIFFLES and cuteSV all required it so germline data was used to filter for these 3 callers. All short read germline data via fastq files was aquired for these patients and I alligned them to the T2T CHM13 reference genome to generate the germline data for each of the patients. From there I started the consensus calling and germline filtering. SAVANNA was unique in that the raw data generation script for SAVANA, I used the command savana to (Tumour-Only mode). I only fed it the tumor BAM file so it was unsure what was an actual variant. Therefore I used an independent SURVIVOR merge to merge the classified, breakpoints, and somatic files and then I ran MANTA on it to filter out the germline data with the previously aquired BAM files for each of the patients. After doing this for SAVANNA, the other vcf files did not such a work around. I used the germline BAM files along with MANTA to ensure the germline data was throughly filtered on the rest of the 8 files produced by cuteSV and SNIFFLES. I then did {Structural_Variants_.vcf-germline_data} on each of the VCF files. From there a consensus was run with SURVIVOR on all 16 files applied alongside a 50bp filter for SV variants which generated the final data.
